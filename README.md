## Лабораторная работа №1. Создание макета страниц сайта

Создала общий макет на Blade с шапкой, меню и подвалом. Добавила главную страницу с приветствием, страницы «О нас» и «Контакты». Данные контактов передаются в шаблон из массива через `view()`.

## Лабораторная работа №2. Вывод данных из JSON-файла

Добавила `MainController` с методом `index()`. Контроллер читает JSON-файл из `public/data/projects.json` и передаёт данные на главную страницу. На главной отображаются карточки с заголовком, описанием и изображением. Превью ведёт на страницу `galery`, где показывается полноразмерное изображение `full_image`. Данные для галереи также получает контроллер.

## Маршруты

| Маршрут | Назначение |
| --- | --- |
| `/` | Главная страница со списком записей из JSON |
| `/galery/{id}` | Галерея выбранной записи |
| `/about` | Страница «О нас» |
| `/contacts` | Страница «Контакты» |

## Основные файлы

- `routes/web.php` — маршруты страниц.
- `app/Http/Controllers/MainController.php` — чтение JSON и передача данных в шаблоны.
- `public/data/projects.json` — данные для карточек.
- `public/images/gallery/` — изображения для превью и галереи.
- `resources/views/home.blade.php` — вывод карточек на главной.
- `resources/views/galery.blade.php` — полноразмерное изображение.
- `resources/views/layouts/app.blade.php` — общий макет сайта.
- `public/css/site.css` — оформление страниц.
- `tests/Feature/` — проверки маршрутов и вывода данных.
