## Цель работы

Научиться работать с маршрутизатором Laravel и шаблонизатором Blade, создать общий макет сайта и несколько страниц.

## Что реализовано

- Общий Blade-макет с шапкой, навигацией, основной частью и подвалом.
- Главная страница с приветственным сообщением.
- Страница «О нас» с текстовой информацией.
- Страница «Контакты» с динамическим выводом данных из массива.
- Маршруты для всех страниц и ссылки между ними.
- Адаптивное оформление сайта.
- В подвале указаны мои ФИО и группа.

## Маршруты

| Адрес | Страница | Имя маршрута |
| --- | --- | --- |
| `/` | Главная | `home` |
| `/about` | О нас | `about` |
| `/contacts` | Контакты | `contacts` |

Маршруты описаны в `routes/web.php`. Данные для страницы контактов передаются в шаблон методом `view()`.

## Основные файлы

- `routes/web.php` — маршрутизация и массив контактов.
- `resources/views/layouts/app.blade.php` — общий макет страниц.
- `resources/views/home.blade.php` — главная страница.
- `resources/views/about.blade.php` — страница «О нас».
- `resources/views/contacts.blade.php` — страница «Контакты».
- `public/css/site.css` — оформление сайта.
- `tests/Feature/PageRoutesTest.php` — проверки страниц.
