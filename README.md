## Лабораторная работа №1. Создание макета страниц сайта

Сделала общий шаблон сайта на Blade с шапкой, меню и подвалом. Добавила главную страницу, страницы «О нас» и «Контакты». Контакты передаются в шаблон из массива через `view()`.

## Лабораторная работа №2. Вывод данных из JSON-файла

Создала контроллер `MainController` с методом `index()`. Контроллер читает файл `public/articles.json` и передаёт массив статей на главную страницу. Карточки формируются через Blade: отображаются названия, даты, описания и изображения из полей `name`, `date`, `shortDesc`, `preview_image`.

При нажатии на `preview_image` открывается страница `galery` с полным изображением `full_image` и текстом статьи. Если в JSON отсутствует `shortDesc`, на главной отображается поле `desc`. Используются исходные данные и изображения из задания.


## Лабораторная работа №3. Регистрация пользователей

Создала страницу регистрации `resources/views/auth/signin.blade.php` с полями «Имя», «Email» и «Пароль». Добавила CSRF-токен (`@csrf`) и отправку данных методом POST на `/signin`.

В `AuthController` реализовала методы `create()` и `registration()`. Первый открывает форму, второй проверяет данные с помощью Laravel `Request::validate()` и возвращает JSON-ответ. Для имени установила обязательное заполнение и ограничение до 80 символов, для почты — проверку формата email, для пароля — длину от 8 до 72 символов. В целях безопасности пароль в ответе скрывается. В этой лабораторной данные не сохраняются.

Добавила ссылку «Регистрация» в основное меню. На главной странице указала своё имя, а на странице «О нас» обновила формулировку про лабораторную работу.

## Маршруты

| Маршрут | Назначение |
| --- | --- |
| `/` | Главная со статьями из JSON |
| `/galery/{id}` | Полное изображение и описание статьи |
| `/about` | Страница «О нас» |
| `/contacts` | Страница «Контакты» |
| `GET /signin` | Форма регистрации |
| `POST /signin` | Валидация и JSON-ответ |

## Основные файлы

- `routes/web.php` — маршруты.
- `app/Http/Controllers/MainController.php` — чтение и обработка JSON.
- `public/articles.json` — данные шести статей.
- `public/preview.jpg`, `public/preview_2.jpg` — превью.
- `public/full.jpeg`, `public/full_2.jpeg` — полные изображения.
- `resources/views/home.blade.php` — карточки статей.
- `resources/views/galery.blade.php` — галерея.
- `resources/views/layouts/app.blade.php` — общий шаблон.
- `tests/Feature/` — тесты страниц и галереи.

- `app/Http/Controllers/AuthController.php` — создание формы и обработка данных.
- `resources/views/auth/signin.blade.php` — форма регистрации.
- `tests/Feature/RegistrationTest.php` — тесты регистрации.
